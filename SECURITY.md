# Security

These are small personal projects, most of them running on a single home
k3s node behind Cloudflare. There is no bounty programme.

If you find a vulnerability in any `caboose-ai` repository, please do not
open a public issue. Use GitHub's private "Report a vulnerability" button on
the repository's Security tab, which opens a draft advisory visible only to
the maintainers. Include the repository, the version or image tag, and steps
to reproduce. You should hear back within a week.

Secrets are never committed to these repositories; if you believe one has
leaked, report it the same way so it can be rotated.
